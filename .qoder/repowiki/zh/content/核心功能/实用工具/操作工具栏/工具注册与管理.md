## 简介
本文档详细解析了操作工具栏的注册与管理机制，重点分析了`useToolManager`自定义Hook的实现原理。该机制为应用程序提供了动态注册、更新和注销操作工具的能力，确保了工具栏的灵活性和可扩展性。

## 核心组件

`useToolManager`是工具注册与管理的核心Hook，它提供了注册和注销工具的接口。该Hook通过`setTools`状态更新函数来管理工具列表，实现了工具的动态添加和移除。

## 注册与注销机制

### registerTool方法
`registerTool`方法用于注册新工具或更新现有工具。当注册同ID的工具时，会替换原有工具。工具注册后会根据`order`属性进行降序排序，确保高优先级的工具显示在前面。

### unregisterTool方法
`unregisterTool`方法通过工具ID从工具列表中移除指定工具，保持工具列表的整洁。

```mermaid
flowchart TD
Start([注册工具]) --> CheckId["检查工具ID是否存在"]
CheckId --> |存在| RemoveExisting["移除现有工具"]
CheckId --> |不存在| Proceed["继续注册"]
RemoveExisting --> Proceed
Proceed --> AddTool["添加新工具到列表"]
AddTool --> SortTools["按order降序排序"]
SortTools --> UpdateState["更新工具状态"]
UpdateState --> End([完成注册])
Start2([注销工具]) --> FindById["通过ID查找工具"]
FindById --> RemoveTool["从列表中移除工具"]
RemoveTool --> UpdateState2["更新工具状态"]
UpdateState2 --> End2([完成注销])
```

## 工具状态同步

工具状态通过父组件的`setTools`函数实现同步。子组件通过`useToolManager`Hook获取注册和注销工具的能力，当工具状态发生变化时，会触发父组件的状态更新，从而实现组件间的工具状态同步。

```mermaid
sequenceDiagram
participant ChildComponent as "子组件"
participant ToolManager as "useToolManager"
participant ParentComponent as "父组件"
ChildComponent->>ToolManager : registerTool(tool)
ToolManager->>ParentComponent : setTools(更新后的工具列表)
ParentComponent-->>ToolManager : 返回新状态
ToolManager-->>ChildComponent : 完成注册
ChildComponent->>ToolManager : removeTool(id)
ToolManager->>ParentComponent : setTools(移除后的工具列表)
ParentComponent-->>ToolManager : 返回新状态
ToolManager-->>ChildComponent : 完成注销
```

## 工具生命周期管理

工具的生命周期包括初始化、更新和销毁三个阶段。通过`useEffect` Hook管理工具的生命周期，在组件挂载时注册工具，在组件卸载时自动注销工具。

```mermaid
stateDiagram-v2

注册工具 --> 运行中 : 工具可用
运行中 --> 更新 : 状态变化
更新 --> 运行中 : 重新注册
运行中 --> 销毁 : 组件卸载
销毁 --> 注销工具 : 清理资源
注销工具 --> [*]
```

## 错误处理与边界情况

### 错误处理
- 当`setTools`未提供时，`registerTool`和`removeTool`方法会安全地跳过状态更新，避免抛出错误。
- 工具ID的唯一性确保了工具的正确替换和移除。

### 边界情况
- 注册已存在的工具：同ID的工具会被新工具替换。
- 注销不存在的工具：操作被安全忽略，不影响其他工具。
- 工具排序：按`order`属性降序排列，确保正确的显示顺序。

```mermaid
flowchart TD
StartError([错误处理])
--> CheckSetTools["检查setTools是否存在"]
--> |不存在| SkipUpdate["跳过状态更新"]
--> NoError["不抛出错误"]
StartEdge["边界情况"]
--> RegisterExisting["注册已存在工具"]
--> ReplaceTool["替换原有工具"]
StartEdge --> RemoveNonexistent["注销不存在工具"]
--> Ignore["安全忽略"]
StartEdge --> SortOrder["工具排序"]
--> Descending["按order降序"]
```
