## 简介

Cherry Studio 是一个支持多LLM提供商的桌面客户端，可在 Windows、Mac 和 Linux 上运行。本指南将详细介绍如何设置完整的开发环境，包括所需软件和工具的版本要求、仓库克隆、依赖安装、环境变量配置以及主进程和渲染进程开发服务器的运行方法。

## 项目结构

Cherry Studio 项目采用模块化设计，主要包含以下目录结构：
- `config/`: 应用升级配置文件
- `packages/`: 包含多个独立的 npm 包，如 AI SDK 提供商、AI 核心功能等
- `resources/`: 静态资源文件，包括许可证、隐私政策和数据库脚本
- `scripts/`: 构建和部署相关的脚本文件
- `src/`: 源代码目录，分为 main（主进程）、preload（预加载脚本）和 renderer（渲染进程）
- `tests/`: 测试文件，包含端到端测试和单元测试

这种结构使得项目具有良好的可维护性和扩展性。

## 技术栈与版本要求

根据项目配置文件，Cherry Studio 的技术栈和版本要求如下：

### Node.js
项目要求 Node.js 版本 >= 22.0.0，这在 package.json 的 engines 字段中明确指定。

### Yarn
项目使用 Yarn 作为包管理器，版本为 4.9.1。这是通过 packageManager 字段指定的。

### TypeScript
项目使用 TypeScript 进行类型检查，版本为 ~5.8.2。

### Electron
Electron 版本为 38.7.0，用于构建跨平台桌面应用。

### 其他关键依赖
- React: ^19.2.0
- Vite: 使用 rolldown-vite@7.1.5
- Tailwind CSS: ^4.1.13
- Ant Design: 通过补丁应用的 5.27.0 版本

这些技术栈的选择确保了项目的高性能和现代开发体验。

2. **Yarn**: 推荐使用 v4.9.1

5. **Electron**: 项目依赖 Electron 构建桌面应用

### 开发工具
推荐使用支持 TypeScript 和 React 的现代 IDE，如 Visual Studio Code，并安装相应的扩展插件以获得最佳开发体验。

## 依赖安装与配置

### 克隆仓库
```bash
git clone https://github.com/CherryHQ/cherry-studio.git
cd cherry-studio
```

### 安装依赖
使用 Yarn 安装所有项目依赖：
```bash
yarn install
```

由于项目使用了 Yarn Workspaces，这将同时安装根目录和所有 packages/* 目录下的依赖。

### 环境变量配置
项目使用 dotenv-cli 来管理环境变量。创建 .env 文件并根据需要配置相关变量：
```bash
cp .env.example .env
```

主要环境变量包括 API 密钥、代理设置等，具体可根据实际需求进行配置。

## 运行开发服务器

### 启动主进程和渲染进程
使用以下命令启动开发服务器：
```bash
yarn dev
```

这将同时启动主进程和渲染进程的开发服务器，提供热重载功能。

### 调试模式
如需启用调试模式，可以使用：
```bash
yarn debug
```

这将启动带有调试选项的 Electron 应用，便于开发者进行调试。

### 预览模式
构建后预览应用：
```bash
yarn start
```

## 常见问题解决方案

### 依赖冲突
由于项目使用了大量第三方库，可能会出现依赖冲突。建议使用 Yarn 的 resolutions 字段来强制指定特定版本的依赖。

### 构建失败
如果遇到构建失败问题，请检查以下几点：
1. 确保 Node.js 版本符合要求
2. 清理 node_modules 并重新安装依赖
3. 检查磁盘空间是否充足

### 类型检查错误
项目配置了严格的 TypeScript 检查。如果遇到类型错误，请根据提示进行修复，或在必要时添加适当的类型断言。

## 不同操作系统的特殊配置

### Windows
Windows 用户需要注意路径分隔符的问题，建议使用 Git Bash 或 WSL 进行开发。

### Mac
Mac 用户需要确保已安装 Xcode 命令行工具，以便编译原生模块。

### Linux
Linux 用户可能需要安装额外的系统库，如 libgconf-2-4 等，以支持 Electron 的某些功能。

所有平台都应确保开发环境的一致性，避免因平台差异导致的问题。

## 构建与打包

### 构建命令
```bash
yarn build
```

这将执行类型检查并构建应用。

### 打包命令
根据不同平台，可以使用以下命令进行打包：
- Windows: `yarn build:win`
- Mac: `yarn build:mac`
- Linux: `yarn build:linux`

这些命令会生成对应平台的可安装包。
